# Сборка SkriNim

[Страница приложения](../README.md)

## Инструменты

Понадобятся Bash, Java, Android SDK Platform 35 и Build Tools 35.0.0. Для подготовки офлайн-распознавания при первой сборке используются curl, zip, unzip и sha256sum.

| Переменная | Значение |
| --- | --- |
| `ANDROID_JAR` | Путь к `platforms/android-35/android.jar` |
| `ANDROID_TOOLS` | Каталог `build-tools/35.0.0` |
| `APK_KEYSTORE` | Путь к хранилищу ключа подписи |
| `APK_KS_PASS` | Источник пароля для apksigner, например `env:APKSIGNER_PASSWORD`, если пароль уже задан в окружении |
| `ECJ_JAR` | Необязательный путь к компилятору Eclipse для сборки вместо javac |
| `OCR_CACHE_DIR` | Необязательный каталог кэша для компонентов распознавания, по умолчанию `build/ocr-cache` |

Из корня репозитория выполни:

```sh
bash build-apk.sh
```

Скрипт проверит компоненты OCR по SHA-256, соберёт APK, подпишет его и проверит подпись через apksigner. Результат появится в `build/SkriNim-<versionName>.apk`. В APK включаются Tesseract4Android 4.9.0 и модели tessdata_fast 4.1.0 для шести языков. [Лицензии компонентов](../assets/licenses/NOTICE.txt)

## Нумерация выпусков

Для каждой устанавливаемой сборки укажи новый, возрастающий `versionCode` в [AndroidManifest.xml](../AndroidManifest.xml). Имя APK берётся из `versionName`. После стабильной 1.1.2 беты следующего патча называются `1.1.2_b.1`, `1.1.2_b.2` и далее, а следующий стабильный патч — `1.1.3`.

Для релиза беты на GitHub укажи **Pre-release**. Проверка обновлений внутри приложения выбирает последний стабильный релиз. Для обновления поверх установленной сборки нужны тот же идентификатор пакета, совместимая подпись и больший код версии.
